# The Etsy Photo-Upgrade Plan — Turn $100 into $400–$500 in 30 Days

Entry for the make.fun bounty [The plan make.fun will carry out in public](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138): a plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## The plan

Sell AI photo upgrades to Etsy sellers: search Etsy, shortlist 50 listings, DM 30 sellers offering sharper photo sets for $15 within 24 hours. Day 1 sends 2 free samples; a paid order by Day 2 proves demand. Ramp to 3 sales a day and upsell $25 lifestyle sets. The edge: sellers can see the flaw in their own photos, so the fix sells itself — and the $100 starting stake is never spent, so the worst case ends with the money intact. Day 30: $400–$500 net.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes the 279-character plan to `/output/entry.txt` and validates it is 1–280 Unicode code points and not only white space.
